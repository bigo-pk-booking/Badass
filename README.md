# BADass Android

Native Android app for BADASS BIGO PK Slots.

- App label: BADass
- Application ID: `com.badass.bigopk`
- Kotlin + Jetpack Compose
- APK builds automatically with GitHub Actions on pushes to `main`.

## Build locally
Open this project in Android Studio and sync Gradle, then run the `app` configuration.

## Backend
This first milestone is a native UI foundation only. It does not yet submit bookings or authenticate admins. Existing backend endpoints and authentication must be verified before enabling live operations.
